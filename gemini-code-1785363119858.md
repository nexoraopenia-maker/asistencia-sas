# CLAUDE.md - Scire 360 Chronos (SaaS de Control de Asistencia)

## Project Overview
Scire 360 Chronos es una plataforma SaaS B2B moderna para la gestión automatizada de asistencia, turnos y horarios de empleados. Permite la marcación móvil (entrada/salida) con verificación por foto selfie, geolocalización (geocercas), control de tiempos en tiempo real (incluyendo desgloses de refrigerio y trabajo) y generación de reportes automáticos para Recursos Humanos.

---

## Visual & UI Mapping (Basado en la Interfaz de la App)

### 1. Ficha del Empleado (Header)
- **Datos Visibles**: Nombre completo (`María Fernández`), Cargo (`Analista de Recursos Humanos`), ID de Empleado (`98451237`) y Avatar.
- **Notificaciones**: Ícono de campana para alertas de turnos, incidencias y recordatorios.

### 2. Módulo de Turnos y Calendario (`Turnos`)
- **Tira Semanal**: Selector horizontal de días (`Dom 12`, `Lun 13`, `Mar 14`, `Mié 15`, `Jue 16`, `Vie 17`, `Sáb 18`).
- **Botón de Acción Rápida**: `Marcar asistencia`.

### 3. Marcación Móvil y Verificación (`Foto lista` / `Marcación móvil`)
- **Verificación Fotográfica**: Captura de selfie en tiempo real al momento de marcar entrada/salida.
- **Estado de Validación**: Badge dinámico de confirmación (`Foto lista` con check verde).

### 4. Detalle del Turno en Tiempo Real (`Detalle del Turno`)
- **Registro con Precisión**: Marca exacta en formato `HH:mm:ss`.
- **Desglose de Rangos**:
  - **Refrigerio**: ej. Ingreso `13:00:00` - Salida `14:00:00`.
  - **Trabajo**: ej. Ingreso `09:00:00` - Salida `18:00:00`.
- **Acciones**: Botones `Ver más` y `Cerrar`.

### 5. Navegación Inferior (Tab Navigation)
- `Inicio` | `Asistencia` | `Calendario` | `Reportes` | `Más`

## Architecture & Tech Stack

### Frontend & Mobile
- **App Móvil**: React Native (Expo) / NativeWind (Tailwind CSS) / React Native Reanimated
- **Portal Web Admin (RRHH)**: Next.js (App Router), React, Tailwind CSS, Lucide Icons, Tremor / Recharts, shadcn/ui

### Backend & Database
- **API Server**: Node.js (TypeScript) con NestJS / Express
- **Base de Datos**: PostgreSQL + Prisma ORM
- **Caché & Sesiones**: Redis
- **Almacenamiento de Archivos (Fotos)**: AWS S3 / Cloudflare R2 (para imágenes de marcación)
- **Automatizaciones & Notificaciones**: n8n, Evolution API (WhatsApp/SMS para alertas de tardanzas o ausencias)
